# Task 3: CSS Selectors

A simple page that practises CSS selectors using only HTML and CSS.

## Files
- `index.html` - the page structure
- `style.css` - all the styles, linked in `index.html`

## Selectors Used
- Element selector: `body`, `p`
- Class selector: `.head`
- ID selector: `#bglime`, `#para`
- Descendant selector: `#bglime span`, `p b`, `ul a`
- `:nth-child()` selector: `ul li:nth-child(2) a`, `ol li:nth-child(2)`, `ol li:nth-child(3)`

## How to Run
Open `index.html` in a browser.
