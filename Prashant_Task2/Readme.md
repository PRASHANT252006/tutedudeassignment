# Laundry Wallah / Laundry Mart – HTML Task

A simple HTML webpage for a laundry service.

## Sections
- **Header:** Welcome heading
- **About:** Short intro paragraph
- **Image:** Laundry image
- **Our Services:** Unordered list of services
- **Price List:** Bordered table with service and price
- **Book Now:** Form with name, email, phone (all required) and a Submit button
- **Footer:** Contact: info@laundrymart.com

## How to Run
1. Open the folder.
2. Double-click `index.html` to open it in a browser.
